# vynamp-decode

Dependency-free audio decoding library in Rust (std only): containers, codecs,
metadata and CUE, with no crates.io dependencies and no `unsafe` in the library crates.

**Status:** pre-alpha, private repository. APIs are unstable and nothing is published.

## Format support

Generated by `cargo run --example support_matrix`:

| Kind | Name | Extensions | Verification |
|------|------|------------|--------------|
| container | riff | .wav .wave .w64 .rf64 .bw64 | oracle |
| container | aiff | .aif .aiff .aifc | oracle |
| container | flac | .flac .fla | conformance |
| container | mpa | .mp3 .mp2 .mp1 .mpa | oracle |
| codec | pcm | - | oracle |
| codec | flac | - | conformance |
| codec | mpeg-audio | - | oracle |
| codec | mpeg-audio-layer1 | - | experimental |

Verification levels: `conformance` (bit-exact against official conformance vectors only;
round trips and self-made tests do not qualify), `oracle` (matches a reference
implementation's output, e.g. the third-party FFmpeg-written PCM corpus), `experimental`.
PCM has no official conformance vectors, so its containers and codec are `oracle`. FLAC
is `conformance`: the IETF CELLAR `flac-test-files` decode bit-exactly in Strict mode.
MPEG audio Layers II and III are `oracle`: the decoder meets the ISO/IEC 11172-4 full
accuracy criterion against FFmpeg's floating point decoders on a 33-file corpus; the ISO conformance
streams are ISO copyright without a clear redistribution licence and are not used. Layer I is
`experimental` (FFmpeg has no Layer I encoder, so there is no third-party oracle for it).
