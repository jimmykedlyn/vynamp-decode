# agulha

Dependency-free audio decoding library in Rust (std only): containers, codecs,
metadata and CUE, with no crates.io dependencies and no `unsafe` in the library crates.

**Status:** pre-alpha, private repository. APIs are unstable and nothing is published.

## Format support

Generated by `cargo run --example support_matrix`:

| Kind | Name | Extensions | Verification |
|------|------|------------|--------------|
| container | riff | .wav .wave .w64 .rf64 .bw64 | - |
| container | aiff | .aif .aiff .aifc | - |
| codec | pcm | - | conformance |

Verification levels: `conformance` (bit-exact against a conformance suite or lossless
round trips), `oracle` (matches a reference implementation's output), `experimental`.
PCM is additionally checked against a third-party FFmpeg-written corpus.

## Documentation

An mdBook source lives in [`book/`](book/) (architecture, usage, adding a codec,
verification). Building it with `mdbook` is optional.
